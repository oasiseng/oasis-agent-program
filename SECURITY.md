# Security and sensitive information

Report an accidentally discovered sensitive issue privately to **agents@oasisengineering.com**, subject `[Oasis agent pilot] Sensitive finding`. Include the affected public URL, a minimal description and the time observed. Do not include credentials or private client data in ordinary email; ask for an appropriate transfer method if needed.

Do not create a public issue, continue probing, access other records, exploit the issue, test credentials, run a scanner/load test, or publish details. This pilot does not authorize security testing or promise a vulnerability reward or response time.

Maintainers: pause verification with `PROGRAM_ENABLED=false` when needed; preserve appropriate incident evidence privately; revoke affected receipts; rotate exposed secrets through Cloudflare. Never paste proof headers, wallet keys or service secrets into GitHub. See [operations](docs/OPERATIONS.md).
